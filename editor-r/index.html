    Como usar

    • Escreva o código no editor e aperte Ctrl+Enter para executar a linha do cursor (ou o trecho selecionado). Um comando que ocupa várias linhas é executado inteiro.
    • Ctrl+Shift+Enter executa o script todo.
    • O botão Novo limpa o editor para começar do zero; em Exemplos… há códigos prontos para testar.
    • Alt+- insere <-; Ctrl+Shift+C comenta ou descomenta linhas.
    • No Console dá para digitar comandos depois do > e apertar Enter, como no RStudio. Se o comando estiver incompleto, aparece + para continuar na linha de baixo. ↑ ↓ recuperam os comandos anteriores, Tab completa nomes, Shift+Enter quebra a linha e Esc apaga o comando.
    • As divisórias entre os painéis podem ser arrastadas para mudar o tamanho de cada um.

    Os painéis

    • Environment: objetos criados na sessão. History: comandos já executados.
    • Files: arquivos da pasta de trabalho, para enviar e baixar. Plots: gráficos. Packages: pacotes instalados. Help: esta ajuda e a documentação do R.

    Documentação do R

    ?mean ou help(mean) mostram aqui a documentação da função (em inglês). Os links para outras funções abrem nesta mesma aba.

    Dados de exemplo

    Alguns arquivos de dados de exemplo já estão na pasta de trabalho, por exemplo read.csv("data/processed/alunos_2023_limpo.csv"). Veja a lista na aba Files, onde também dá para enviar seus próprios arquivos e baixar os que o R criar (com write.csv(), por exemplo).

    Pacotes

    Instale com install.packages("dplyr") e carregue com library(dplyr), como no RStudio (se esquecer o install.packages(), o library() instala sozinho). A instalação precisa ser repetida sempre que a página é aberta. A maioria dos pacotes do CRAN funciona; os que dependem de programas externos (como odbc ou rJava) não funcionam.

    Bom saber

    • O R roda no seu navegador: nenhum código ou arquivo é enviado para um servidor.
    • O script fica salvo neste navegador. Os objetos, pacotes e arquivos enviados se perdem ao recarregar a página.
    • O primeiro carregamento baixa cerca de 30 MB; depois fica mais rápido.
